# DocStation

> DocStation is a unified pharmacy care and medical billing platform that helps community and clinical pharmacies bill insurance for the clinical services they already provide — vaccines, MTM, point-of-care testing, consultations, and DME. It consolidates patient records, medical claims, scheduling, messaging, workflow automation, and revenue analytics into one HIPAA-compliant, SOC 2 Type II system. DocStation publishes NO public developer API, no OpenAPI, no SDK, and no MCP server; its integrations are credentialed per customer and enabled from inside the authenticated application. This profile is maintained by the API Evangelist network and is not affiliated with DocStation.

## Integrations (no public API)
DocStation has no developer portal, no API reference, no OpenAPI/GraphQL/AsyncAPI document, and no public endpoint catalog. Integration is arranged through DocStation support and the in-app integrations screen:
- PioneerRx — DocStation issues an Endpoint URL, username and password; PioneerRx pushes dispensing data to `https://webhooks.docstation.co/api/webhooks/pioneerrx/`. Requires a signed Data Collection and Transfer Agreement.
- Liberty RXQ — connected with an API PIN taken from Liberty's own settings.
- DRX Pharmacy Software — connected with a DRX API key plus an org slug.
- RelayHealth — clearinghouse; converts prescription claims to medical claims.
- CPESN USA — submission of Level 1 certified pharmacist eCare Plans.
- DHS Immunization Gateway (IZG) — bi-directional immunization feed; onboarding via support@docstation.co.
